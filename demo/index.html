What these numbers mean
Each SQL variant was sent to BigQuery with dryRun: true and useQueryCache: false. The page replays estimates and schema, plus three sequential execution samples for eligible queries.
Engine time comes from job start/end timestamps. Client time includes request and result retrieval. Slot-ms measures aggregate compute work, not wall time or an on-demand charge. Cache was disabled; storage warmth, slot availability and execution order were not controlled.
The default $6.25/TiB is an adjustable US on-demand list-rate assumption, checked on 4 October 2026. Google pricing ↗

Reproduce in your own project
npm install @google-cloud/bigquery
gcloud auth application-default login
# Set GOOGLE_CLOUD_PROJECT to your sandbox project.
npm run record:estimates
# Optional: three capped samples per eligible query
npm run record:estimates -- --benchmark
# Or only two aggregate checks, at 50 MB each
npm run record:estimates -- --verify-summary
The default recorder performs dry runs only. Benchmarks cap each attempt at 300 MB and reserve it against a 15 GB batch ceiling. Refreshed sources can make a previously eligible query fail the cap. Missing runs remain unknown.
