    Read and cost

    Data read is the dry-run scan estimate. Estimated cost is bytes ÷ 2⁴⁰ × USD/TiB. Measured cost uses observed billed bytes; it can differ because of pruning and billing minimums.

    Enter a rate from 0 to 1000 USD/TiB.

    Time and output

    Engine time is job end minus start. Client time includes submission, network, polling and result retrieval. Slot-ms is accumulated compute work, not elapsed time or an on-demand charge.
