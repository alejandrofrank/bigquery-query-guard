What these numbers mean
Each SQL variant was sent to BigQuery with dryRun: true and useQueryCache: false. The page replays the saved estimates and output schema. Dry runs do not return data rows.
Actual billed bytes can differ, including through block pruning, query caching and billing minimums. These are on-demand processing estimates, not dollar savings.

Current recording
The public Bitcoin endpoints are views. We do not infer their physical partition counts from these measurements.

      
Reproduce in your own project
npm install @google-cloud/bigquery
gcloud auth application-default login
# Set GOOGLE_CLOUD_PROJECT to your sandbox project.
npm run record:estimates
# Optional: execute two capped count checks
npm run record:estimates -- --verify-summary
The default recorder performs dry runs only. The optional check executes two aggregate queries, each capped at 50 MB.
